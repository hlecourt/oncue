# Security

Found a vulnerability? Please do not open a public issue. Report it privately through
[GitHub](https://github.com/hlecourt/oncue/security/advisories/new), or by email to hlecourt.pro@gmail.com.

Tell me the version, how you run OnCue (Docker, Bazarr hook, standalone), what an attacker would need (access to the UI, write
access to the media folder, a crafted subtitle or video) and how to reproduce it.

You will get an answer within 7 days. The fix ships as soon as it is ready, and the advisory is published once people have had
time to upgrade, normally within 90 days. You are credited unless you would rather not be.

Only the latest release gets fixes: OnCue is young (0.x), so please upgrade before reporting.

How OnCue protects its web UI, your files and Bazarr's key: [docs/security.md](docs/security.md).
